# OD_Image_YOLO12

**YOLO12 - Image track - training and test evaluation**

Part of the *Physical AI Object Detection* reference series of the **Statera Working Group**:
one algorithm and one task per repository, the same data, protocol and metrics for every algorithm -
only the algorithm differs.

## Model

- Paper: Tian, Ye & Doermann, *YOLOv12: Attention-Centric Real-Time Object Detectors*, arXiv:2502.12524
- Implementation source: official Ultralytics YAML cfg/models/12/yolo12.yaml + official blocks / head / loss; size n
- Parameters: 2.58 M (36 classes)

- Backbone / neck: A2C2f = R-ELAN with area attention (flash-attention optional)
- Head: Detect as YOLO11

Detection layer / assignment / loss: Task-Aligned Assigner + BCE + CIoU + DFL (official v8DetectionLoss); STAL off

Differences from the original (common protocol):

- Training recipe replaced by the common protocol

## Data: FashionLetters36 (synthetic, generated by step 1)

36 classes = Fashion-MNIST (10) + EMNIST letters (26); 608 x 608 canvases with 3-10 non-overlapping objects of 32-160 px; 4,096 train / 1,024 test images, fixed seed - every user generates the same dataset. Purpose: verify that the algorithm is implemented correctly (it must converge on this controlled data), separately from benchmarking on VOC / COCO.

EMNIST is downloaded from NIST; if the download is refused, fetch `gzip.zip` in a browser from https://www.nist.gov/itl/products-and-services/emnist-dataset and run `python data_processing_fl36.py --emnist-zip <path>/gzip.zip`.

## Results

> **v1.1 (2026-10-22)** - The v1.0 results and weights covered only the 10 Fashion-MNIST classes: a class-name case bug (`"F"` was looked up as `"f"`) dropped the 26 letter classes from training and evaluation (4,848 of the 6,699 test objects). v1.1 fixes `common/datasets/voc.py` and reports a re-training on all 36 classes. The v1.0 Release is kept for reference.

Test set: FashionLetters36 test (1,024 images, 36 classes), IoU 0.5, after 30 epochs (0.6 h on an RTX 4070 Laptop GPU).

| mAP50 | Recall | Final train loss | Train class accuracy |
| --- | --- | --- | --- |
| **0.8178** | 0.896 | 3.828 | 77.5 % |

Convergence (test mAP50):

| Epoch | 5 | 10 | 15 | 20 | 25 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| mAP50 | 0.348 | 0.564 | 0.672 | 0.732 | 0.789 | 0.818 |

Protocol: 30 epochs, Adam lr 1e-4 (constant), effective batch 8 (micro batch 2 x 4 accumulation), input 608, seed 777, no pretraining; augmentation: horizontal flip + the basic YOLO-paper augmentation (random scale / translation 20 %, HSV hue 0.1, saturation / exposure 1.5); test mAP50 every 5 epochs.

## Usage

```bash
pip install -r requirements.txt
python data_processing_fl36.py          # downloads Fashion-MNIST + EMNIST, generates FashionLetters36
python train_image_v12.py               # training, then test evaluation (runs/image_v12/)
python evaluate_image_v12.py            # test evaluation of runs/image_v12/checkpoints/ (or --weights <file>)
```

Data are expected under `$PHYSICAL_AI_ROOT/datasets` (default `~/Physical_AI/datasets`).
Smoke test: `python train_image_v12.py --epochs 1 --max-train 8 --max-test 4`.

Trained weights: the GitHub Release of this repository contains `image_v12_fl36_e030.pth` (the run reported above).
Put it into `runs/image_v12/checkpoints/` or pass `--weights <file>` to the evaluation script.
Demo scripts using these weights will be added in a later release.
